\caption{Classical field-oriented control (FOC) structure for a three-phase
permanent magnet AC motor. The measured phase currents are transformed from the
three-phase reference frame to the stationary $\alpha\beta$ frame using the
Clarke transform and subsequently to the rotating $dq$ reference frame using the
Park transform. The current controller regulates the $d$-axis and $q$-axis currents
independently. The resulting voltage references are transformed back to the
$\alpha\beta$ frame through the inverse Park transform and converted into
three-phase PWM duty cycles using space vector modulation (SVM). The electrical
angle is derived from the encoder measurement according to $\theta_e=p\,\theta_m$,
where $p$ is the number of pole pairs.}
\label{fig:foc-complete-loop}
